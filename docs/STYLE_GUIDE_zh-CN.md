# 知识笔记写作规范

[English](STYLE_GUIDE.md) | [简体中文](STYLE_GUIDE_zh-CN.md)

题目 README 只保留轻量来源卡片。可复用推理写入
`knowledge/<category>/<topic>/` 下的双语页面，关系与生命周期事实由 `topic.toml` 保存。

## 必需结构

- **概览**：定义可复用知识及其适用范围。
- **识别信号**：记录什么题面特征会提示使用这个模型。
- **建模**：先定义状态、选择、不变量或数学对象，再给公式。
- **推导**：从模型重建递归、记忆化、递推顺序和正确性，不只陈列需要背诵的转移式。
- **变体**：区分通用替代方案、优化，以及依赖特殊约束的数学捷径。
- **例题**：说明每道关联题贡献了什么，不复制完整题面。
- **复习记录**：保存真实回忆结果和下一次可执行的改进点。

“图解”“证明细节”“练习”等章节只在有帮助时添加。只有当一个小节拥有独立定义、被多个页面
复用，或形成自己的复习问题与例题集合时，才拆成独立主题。

## 图解

不要添加装饰性图片。只有当关系、状态依赖或推导序列借助视觉能明显更容易重建时才使用图解。
简单关系优先使用紧凑、可审查的图；Mermaid 难以清楚表达的精细推导，可以在主题的 `assets/`
目录保存 PNG 或 SVG。图片必须有有效替代文本，正文也应在看不到图片时保持完整。

一张图服务于共享知识类别，不按相似题重复制作。外部思路或视觉对内容有实质影响时应注明来源。

## 语言与复习

英文放在 `README.md`，自然中文放在 `README_zh-CN.md`；两者语义对齐，但不逐句直译。先定义
符号，保持术语一致，避免流水账叙事，完整 Accepted 代码继续留在 `problems/`。

复习记录只追加、不美化旧历史。使用 ISO 日期，记录真实结果，并留下一个会影响下次复习的具体
观察。
